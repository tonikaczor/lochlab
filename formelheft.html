R = U / I
P = U · I = I² · R

U₁ / U₂ = R₁ / R₂
Potentiometer
Uaus = Uein · R2 / (R1 + R2)
Leiterwiderstand und Temperaturabhängigkeit
R = ρ · l / A
ΔR = α · R₂₀ · Δϑ
R_ϑ = R₂₀ + ΔR
Spannungsfall: ΔU = I · R

Einphasig: ΔU = I · ρ · 2l / A

Verbraucher
I = P / U

UKl = U0 − I · Ri
Energie, Ladung und Kosten

Energie zurücksetzen
W = P · t

2. Kondensator, Spule und Wechselstrom

Kondensator
C = Q / U
τ = R · C
XC = 1 / (2 · π · f · C)
Kapazität, Ladung und Zeitkonstante
C = ε₀ · εr · A / d
Q = C · U
Spule
u = L · di / dt
XL = 2 · π · f · L
τ = L / R
Induktion und Lenzsche Regel
ui = −N · ΔΦ / Δt
ui = B · l · v (Leiter im Feld, senkrecht bewegt)
Blindwiderstände und Blindleistung
XL = 2π · f · L
XC = 1 / (2π · f · C)
Z = √(R² + X²)
Wechselspannungsquelle
û = √2 · Ueff
T = 1 / f
Wechselgrößen und Induktionsgesetz
f = 1 / T
û = √2 · U
φ = 360° · Δt / T
Mischspannung, Effektivwert und Scheitelfaktor
UDC = (umax + umin) / 2 (symmetrische Form)
Ueff = √(UDC² + UAC²)
Sinus: UAC = ûAC / √2
Scheitelfaktor: k = û / Ueff
Formfaktor: F = Ueff / Gleichrichtwert
RC-Glied: Zeitkonstante, Grenzfrequenz und Phasenverschiebung
fg = 1 / (2π · R · C)
Tiefpass: φ = −arctan(2π · f · R · C)
Hochpass: φ = arctan(1 / (2π · f · R · C))
Tiefpass: ua / ue = 1 / √(1 + (2π · f · R · C)²)
Laden: uC = U · (1 − e^(−t/τ))
Leistungsmesser
P = U · I
P = U · I · cos φ (Wechselstrom)
Frequenzgang-Messplatz (Bode)
fg = 1 / (2 · π · R · C)
a = 20 · lg(Uaus / Uein) in dB
Transformator
U1 / U2 = N1 / N2
I1 / I2 = N2 / N1

U₁ / U₂ = N₁ / N₂ = I₂ / I₁
Z₁ = (N₁ / N₂)² · Z₂
η = Pab / Pzu

3. Drehstrom und Motoren

Drehstromleistung und Verkettung
P = √3 · U · I · cos φ
S = √3 · U · I
Stern: U = √3 · UStr
Dreieck: I = √3 · IStr
Neutralleiterstrom bei ungleicher Last
IN = |IL1 + IL2 + IL3| (Zeigersumme)
gleicher Phasenwinkel: IN = √(I₁² + I₂² + I₃² − I₁ · I₂ − I₂ · I₃ − I₃ · I₁)
symmetrisch: IN = 0
Drehfelddrehzahl und Schlupf
n₀ = f / p
s = (n₀ − n) / n₀
f₂ = s · f₁
Gleichstrommotor: Spannung, Drehzahl, Drehmoment
U = Ui + IA · RA
Ui = c · Φ · n
Mi = c · Φ · IA / (2π)
n = (U − IA · RA) / (c · Φ)

4. Halbleiter, Transistor und Operationsverstärker

Leuchtdiode
RV = (Uq − UF) / IF
Transistor
IC = B · IB
RB = (Ust − UBE) / IB
Basisvorwiderstand und Stromverstärkung
RB = (UB − UBE) / IB
IB = ü · IC / B
PV = UCE · IC
Transistor-Kennlinien und Stromverstärkung
B = IC / IB
Arbeitspunkt grafisch bestimmen
IAP = UB / (R₁ + R₂)
Achsenpunkt: Imax = UB / R₂
Verlustleistungshyperbel
PV = U · I
Grenzkurve: I = Ptot / U
zulässig: U · I < Ptot
Transistor: PV ≈ UCE · IC
MOSFET
PV = ID² · RDS(on)
Heißleiter
RT = R25 · e^(B · (1/T − 1/T25))
Kennlinienschreiber
Rstat = U / I
rdiff = ΔU / ΔI
Vorwiderstand einer Z-Diode
RV = (Ue − UZ) / (IZ + IL)
IZmax = Ptot / UZ
PV = (Ue − UZ)² / RV
Vorwiderstand der Z-Dioden-Stabilisierung
RV,min = (Ue,max − UZ) / (IZ,max + IL,min)
RV,max = (Ue,min − UZ) / (IZ,min + IL,max)
Operationsverstärker
Vu = 1 + Rf / Rg
Vu = −Rf / R1

invertierend: v = −R₂ / R₁
nichtinvertierend: v = 1 + R₂ / R₁

6. Digitaltechnik, Zahlensysteme und Wandler

Boolesche Gesetze
NICHT (A · B) = NICHT A + NICHT B
NICHT (A + B) = NICHT A · NICHT B
A + A · B = A
A + NICHT A · B = A + B
Dualzahl in Dezimalzahl umrechnen
Z = Σ aₙ · 2ⁿ (aₙ = 0 oder 1)
Hexadezimal und Dual
1 Hexziffer = 4 Bit
Zweierkomplement und Subtraktion
−B = NICHT B + 1
A − B = A + NICHT B + 1
Wertebereich bei n Bit
Anzahl Werte = 2ⁿ
größter Wert (ohne Vorzeichen) = 2ⁿ − 1
Zweierkomplement: −2ⁿ⁻¹ … +2ⁿ⁻¹ − 1
KV-Diagramm: Felder und Blockregeln
Felder = 2ⁿ
Block mit 2ᵏ Feldern spart k Variablen
Teilerverhältnis von Zählern
faus = fein / 2ⁿ
Zählumfang = 2ⁿ (Modulo)
Fan-out-Rechnung
FO = IOL(max) / IIL
ILast = Summe(Fan-in) · IIL
Frequenz des 555 (astabil)
tH = 0,693 · (R1 + R2) · C
tL = 0,693 · R2 · C
f = 1,44 / ((R1 + 2 · R2) · C)
Tastverhältnis = tH / (tH + tL)
Impulsdauer des 555 (monostabil)
T = 1,1 · R · C
R = T / (1,1 · C)
Speicherkapazität und Adressleitungen
Stellen = 2ⁿ
Kapazität = Stellen · Wortbreite
Adressraum = 2ⁿ Adressen (n Adressleitungen)
Bussystem (Adress-, Daten-, Steuerbus)
Adressen = 2ⁿ (n = Zahl der Adressleitungen)
Auflösung, LSB und Wandlung (ADU, DAU)
ΔU = Uref / 2ⁿ (ein LSB)
N = Ue / ΔU
DAU: Ua = Uref · N / 2ⁿ
Stufenzahl = 2ⁿ
Abtasttheorem: fAbtast > 2 · fmax
Zweiflankenverfahren (Dual-Slope)
Ux · T₁ = Uref · T₂
Ux = Uref · T₂ / T₁

11. Rechnen, Qualität und Entgelt

Dreisatz (proportional und antiproportional)
proportional: y₂ = y₁ · x₂ / x₁
antiproportional: y₂ = y₁ · x₁ / x₂
Prozentrechnung
W = G · p / 100
p = W / G · 100 %
G = W · 100 / p
Ausschussquote und Ausbeute
Ausschussquote = Ausschuss / Gesamtmenge · 100 %
Ausbeute = Gutteile / Gesamtmenge · 100 % = 100 % − Ausschussquote
Prozessfähigkeit (Cp und Cpk)
Cp = (OSG − USG) / (6 · σ)
Cpk = min( (OSG − x̄) / (3 · σ) ; (x̄ − USG) / (3 · σ) )
Von Brutto zu Netto
Netto = Brutto − Steuern − Arbeitnehmeranteile Sozialversicherung
Auszahlung = Netto − sonstige Abzüge
Stundenlohn = Monatsentgelt / Monatsstunden
